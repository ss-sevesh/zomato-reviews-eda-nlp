# Data

Place the two Zomato source CSV files in this folder (or next to the notebook):

- `Zomato Restaurant reviews.csv` – 10,000 reviews × 7 columns
- `Zomato Restaurant names and Metadata.csv` – 105 restaurants × 6 columns

The notebook reads them via `REV_PATH` / `META_PATH` in the first code cell. Update those paths to `data/...` if you keep the files here.
